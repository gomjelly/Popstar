# Popstar ★

프로젝터와 카메라로 하는 아이들용 AR 체감 게임 모음입니다. 카메라가 사람의 자세를 인식하고, 화면에는 카메라 영상 대신 **관절로 그린 캡슐 아바타**가 나옵니다. 아이들은 2~3m 떨어져서 **손을 들어 버튼 위에 잠깐 멈추는 것**만으로 메뉴를 고릅니다.

**게임 세 가지**(벽 뚫고 지나가기 1인, 풍선 터뜨리기 1인·2인 협동·2인 대결, 낚시 1인·2인 대결)와 **메인·플레이어 추가/관리·명예의 전당**까지 만들었습니다(SRS 8.2의 1~4단계 + 5단계 중 명예의 전당). 스냅샷·포토 스트립은 아직입니다.

## 기술 구성

- **Electron** 데스크톱 앱(프로젝터 출력 모니터 선택·전체화면, 카메라 권한) + **Vite + TypeScript**
- **MediaPipe Pose Landmarker**: 사람을 3명까지 찾고 그중 참가자(1~2명)만 추적, 33개 관절. **작업 스레드(Web Worker)에서 인식**해 화면이 끊기지 않음
- **Three.js** 정사영 카메라로 캡슐 아바타 그리기
- **IndexedDB**: 플레이어(사진은 정사각 JPEG), 명예의 전당, 판 기록(스냅샷 저장소는 다음 단계용). 영상·사진은 기기 밖으로 나가지 않습니다
- 효과음·배경음악: Web Audio로 합성(외부 음원 없음). 나중에 CC0 음원으로 바꿀 수 있습니다(아래 "음원 바꾸기")
- 모델·WASM 파일을 `public/` 에 넣어 **인터넷 없이** 동작합니다

[Wakeline](https://github.com/gomjelly/Wakeline)의 Electron 설정, MediaPipe 에셋 준비, 카메라·자세 인식, 효과음 합성 구조를 가져와 고쳐 썼습니다.

## 설치와 실행

Node **22.12 이상**이 필요합니다(`.nvmrc`, `engine-strict`).

```bash
npm install
```

설치가 끝나면 `postinstall` 이 MediaPipe WASM을 `public/mediapipe/wasm` 으로 복사하고 자세 모델(lite·full·heavy)을 `public/models` 로 내려받습니다. 실패하면 `npm run setup:assets` 로 다시 받습니다.

```bash
npm start
```

빌드 후 Electron 앱을 엽니다. 개발 중에는 `npm run dev`(Vite + Electron, 코드 고치면 바로 반영)를 씁니다.

### 프로젝터 연결

1. 노트북에 프로젝터를 연결하고 `npm start`
2. 메인 화면의 **⚙️ 설정** → **출력 모니터**에서 프로젝터 선택 → **이 모니터로 보내기**
3. **F11** 로 전체화면. 고른 모니터와 전체화면 여부는 다음 실행 때도 유지됩니다

### 카메라

- 별도 카메라를 투사 화면 아래 가운데에 두고 정면으로 찍습니다. 플레이 공간은 카메라에서 2~3m, 폭 약 3m
- ⚙️ 설정 → **카메라**에서 고릅니다. 고른 카메라는 다음 실행 때도 그대로 씁니다
- 카메라가 없으면 **동영상 파일**이나 **화면/창 캡처**를 입력으로 고를 수 있습니다(동영상은 창에 끌어다 놓아도 열림)

## 조작

| 조작 | 손 커서 | 마우스·키보드 |
| --- | --- | --- |
| 버튼 고르기 | 손을 들어 버튼 위에 1.5초 머무르기(원형 게이지가 참) | 클릭 / 화살표로 이동 후 Enter |
| 뒤로 | 왼쪽 위 ◀ 뒤로 | Esc |
| 멈춤·계속(아바타 확인 화면) | ⏸ 멈춤 버튼 | 스페이스 |
| 카메라 보기/숨기기(게임 중에도) | – | 왼쪽 아래 📷 버튼 / V |
| 메뉴 손 조작 켜기/끄기(기본 꺼짐) | – | 왼쪽 아래 🖐 버튼 / H |
| 소리 끄기/켜기 | – | M |
| 전체화면 / 개발자 도구 | – | F11 / F12 |

메뉴는 기본으로 **마우스·키보드**로 고릅니다. 왼쪽 아래 **🖐 손 조작**을 켜면(설정에도 있음, 다음 실행 때도 유지) 손 커서로도 고를 수 있습니다. 게임이 시작되면 몸 동작은 언제나 게임 조작에 쓰이고, 이 버튼은 숨겨집니다.

손 커서는 **손을 든 쪽 어깨 옆 공간**을 화면 전체에 대응시킵니다. 그래서 멀리 서 있어도 팔만 뻗으면 화면 끝까지 닿습니다. 손을 내리면 커서가 사라집니다. 버튼을 고른 직후 화면이 바뀌면, 커서가 한 번 버튼에서 벗어나야 다시 고를 수 있습니다(연달아 잘못 골라지지 않게).

## 화면 흐름

메인(**게임 종류** 벽 뚫기 / 풍선 / 낚시 + **명예의 전당** + **설정**) → 게임 종류를 고르면 **인원 고르기**(풍선: 1인 / 2인 협동 / 2인 대결, 낚시: 1인 / 2인 대결. 벽 뚫기는 1인뿐이라 건너뜀) → **플레이어 선택**(등록한 플레이어 카드, 손님 카드. 플레이어 추가는 "✏️ 플레이어 관리"의 ➕) →

- 풍선 터뜨리기: **양팔 펴기 보정** → 3초 카운트다운 → 30초 스테이지 반복 → **결과**
- 벽 뚫고 지나가기: **준비 자세(체형 측정 3초)** → 결과 확인 → 3초 카운트다운 → 벽 7~10개 → **결과**
- 낚시: **준비 자세(2초)** → 3초 카운트다운 → 90초 동안 던지고 낚기 → **결과**

- **플레이어 추가**: 카메라 앞에 서면 얼굴에 가이드 원이 뜨고, 정면을 보면 3초 카운트다운 후 찍습니다. 얼굴 관절(코·눈·귀) 기준 정사각형으로 잘라 저장하고 다시 찍을 수 있습니다. 이름은 키보드로 8자까지, 같은 이름은 등록할 수 없습니다. 색은 8가지 중 고르고, 기본은 겹치지 않는 색이 자동으로 골라집니다
  - 2~3m 떨어지면 얼굴이 작아 사진이 흐릿합니다. 사진 찍을 때는 한두 걸음 앞으로 오게 하세요
- **준비 자세**: 기준 자세 윤곽이 나오고, 머리부터 발목까지 보여야 진행합니다(잘리면 "한 걸음 뒤로 가요" 등 안내). 2초 동안 가만히 서 있으면 키와 서 있는 자리를 평균 내어 **정규화 변환을 고정**합니다. 이때 왼쪽 사람이 **P1(파랑)**, 오른쪽이 **P2(빨강)** 가 됩니다
- **아바타 확인**: 두 사람의 아바타가 키와 상관없이 **같은 크기(화면 높이의 60%)** 로 보이고, 실제로 움직인 만큼 화면에서도 움직입니다. 자리를 바꿔도 색과 이름표가 따라갑니다. 한 명이라도 2초 넘게 안 보이면 "어디 갔어요? 카메라 앞으로 돌아와요"로 멈추고, 모두 돌아와 1초가 지나면 이어서 합니다
- **여러 사람이 보일 때(구경꾼)**: 사람을 최대 3명까지 찾고 그중 참가 인원(1인 게임 1명, 2인 게임 2명, 메뉴 2명, 사진 찍기 1명)만 추적합니다. 처음에는 우선순위(화면 가운데에 가까움 × 관절이 잘 보임 × 카메라에 가까움)가 높은 사람을 고르고, 게임 전에는 더 높은 사람이 0.7초 넘게 꾸준히 보이면 자리를 넘깁니다. 게임이 시작되면 위치와 옷 색으로 그 사람만 따라가고, 너무 멀거나 옷 색이 다른 사람으로는 넘어가지 않습니다
- **플레이어 관리**(FR-PLY-04): ⚙️ 설정 또는 플레이어 선택 화면의 "✏️ 플레이어 관리"에서 이름·색 바꾸기, 사진 다시 찍기, 삭제. 삭제할 때 명예의 전당 기록도 함께 지울지 묻습니다. 명예의 전당은 플레이어의 **지금** 이름·색·사진으로 보여서 편집이 바로 반영됩니다(기록을 남기고 지운 플레이어는 기록 당시 이름으로, 사진 없이)
- **명예의 전당**: 게임이 끝나면 점수를 게임별(벽 뚫기, 풍선 1인·2인 협동·2인 대결, 낚시 1인·2인 대결)로 자동 저장하고 상위 10개만 남깁니다. 1~3위를 시상대로 보여 주고(플레이어 사진·이름·점수·날짜, 풍선은 도달 스테이지, 낚시는 잡은 물고기 수, 1위는 왕관), 4~10위는 아래에 작게. 3위 안에 들면 결과 화면에 "명예의 전당 N위에 올랐어요!". 2인 협동은 두 사람을 나란히 한 기록으로, **2인 대결은 두 사람이 각자 자기 점수로 따로** 오릅니다(손님은 빼고). **손님끼리만 한 판은 오르지 않습니다**(FR-PLY-06, 결과 화면에 안내)

### 풍선 터뜨리기(2단계)

- **플레이 영역 보정**: 사람 수만큼 인식되면 "양팔을 옆으로 쭉 펴세요"가 나오고, 2초 버티는 동안 손이 닿는 범위를 잽니다(좌우 = 어깨 중심 ± (어깨너비/2 + 팔 길이 + 옆걸음 여유), 위 = 머리 위 팔 길이, 아래 = 무릎). 2인은 왼쪽 사람이 P1이고, 몸 사이가 팔 길이 1개보다 가까우면 "조금 떨어져 서세요"
- **가상 하늘**: 손이 닿는 범위는 화면 아래쪽(높이의 약 47%)에 놓고, 그 위 50%는 카메라와 상관없는 하늘입니다. 풍선·폭탄은 화면 꼭대기에서 생겨 하늘을 지나는 2초 가까이 미리 보이므로 피하거나 기다릴 수 있습니다
- **풍선**: 일반 +10, 황금(빠름) +50, 비눗방울(스치기만 해도) +5, 폭탄(터뜨리면 목숨 −1), 하트(목숨 +1, 최대 5), 시계(3초간 느리게), 별(화면의 일반 풍선 모두 터뜨림). 연속으로 터뜨리면 5콤보 ×1.5, 10콤보 ×2
- **목숨·스테이지**: 목숨 3개(2인 협동은 공유, **2인 대결은 각자**: 폭탄은 친 사람이, 놓친 풍선은 그 풍선에 가까이 있던 사람이 잃음. 목숨이 먼저 다 떨어진 사람은 탈락하고 남은 사람은 계속, 둘 다 탈락하면 끝, 이긴 사람은 점수로). 놓친 풍선 5개마다 목숨 −1. 30초를 버티면 남은 목숨 × 100 보너스(대결은 각자) 후 다음 스테이지. 스테이지마다 더 자주·빨리·작게, 폭탄은 많아지고, 4스테이지부터 바람이 붑니다. 배경은 아침 → 노을 → 밤하늘, 음악은 조금씩 빨라집니다
- **2인 협동**은 점수를 함께, **2인 대결**은 터뜨린 사람 색으로 점수가 떠오르고 각자 점수에 더합니다
- 게임 중에는 손 커서가 꺼지고 이름표는 흐려집니다(멈추려면 스페이스 / ⏸ 버튼, 일시정지 창에서는 손 커서로 고를 수 있음). 결과 화면에서 다시 하기 / 처음으로. 한 판 기록은 IndexedDB `plays` 에 저장합니다

### 낚시

- **던지기**: 한 손을 머리 위로 들었다가 앞(아래)으로 빠르게 휘두릅니다. 손이 어깨 위(몸통 0.3배 넘게)까지 올라갔다가 1초 안에 거기서 몸통 0.4배 넘게 빠르게 내려오면 던진 것으로 봅니다(끝까지 내리지 않아도 됨, 천천히 내리는 건 무시). **빨리 휘두를수록 멀리**(화면에서 수평선 쪽으로) 날아가고, 멀리 던질수록 점수가 최대 1.3배
- **기다리기**: 찌가 물에 뜨면 가만히 기다립니다(1.5~4.5초 무작위). 그 사이 물고기가 자주 **톡톡 건드리는 속임수 입질**(게이지가 쓰레기 칸 위쪽까지 살짝 오름)이 있는데, 이때 당기면 쓰레기가 올라옵니다
- **타이밍 게이지**: 진짜 입질이 오면 찌 옆(2인은 화면 양쪽 끝) 게이지가 아래에서 위로 차오르고(0.9초), 꼭대기 금색 칸에 잠깐(0.3초) 머물렀다가 빠집니다(0.7초). **찌도 게이지만큼 물속으로 쑥 들어갑니다**. 꼭대기에서는 "지금 당겨요!"
- **당기기**: **던진 손으로** 팔을 접어 손을 어깨 높이 위로 올립니다(1초 안에 몸통 0.2배 넘게 올라 어깨 위 0.1배). 다른 손으로 당기면 무시하고 "던진 오른손(왼손)으로 당겨요!"라고 알려 줍니다. 빨리 흔들어 손목 인식이 흐릿해도(visibility 0.1 이상) 위치를 씁니다. 당긴 순간 게이지 값으로 잡히는 게 정해집니다: 금색(0.9 이상) **대어**(고래 500 · 상어 320 · 문어 260), 초록(0.65~) 복어·오징어·열대어(110~150), 하늘색(0.4~) 작은 물고기·꽃게·새우(40~60), 회색(그 아래)이나 너무 빨리 당기면 **쓰레기**(장화·깡통·양말 0점, 물풀 5점). 놓치면 물고기가 도망가고 다시 기다립니다
- **2인 대결**: 왼쪽 P1, 오른쪽 P2가 각자 낚싯대·게이지·점수를 갖고, 찌는 자기 쪽 절반에만 떨어집니다. 90초가 끝나면 점수로 승패, 명예의 전당에는 각자 자기 점수로 오릅니다
- 값은 `game.config.json` 의 `fishing` 에서 바꿀 수 있습니다(시간, 기다림, 게이지 빠르기, 등급 경계, 동작 문턱)

### 벽 뚫고 지나가기(3·4단계)

- **체형 측정**(FR-WALL-01~05): 기준 자세(다리 어깨너비, 팔 내림) 윤곽에 맞춰 머리부터 발목까지 보이게 서서 3초 버티면, 프레임 평균으로 키·어깨너비·골반너비·위팔·아래팔·허벅지·정강이·머리 크기를 잽니다(키를 1로 둔 비율). 키가 화면 높이의 60%로, 서 있던 자리가 화면 가운데가 되게 변환을 고정하고, 결과를 아바타와 숫자로 보여 준 뒤 **다시 재기 / 좋아요, 시작!** 을 고릅니다. 등록 플레이어면 체형을 플레이어에 저장합니다
- **자세 라이브러리**: `public/config/poses.json` 에 21개(별, 만세, T자, 브이, 근육 자랑, 허수아비, 로봇, 기마자세, 플라밍고, 비행기, 발레리나, 옆차기 등, 레벨 1~3). 각도 정의는 SRS 6장과 같고, 팔꿈치·무릎은 + 가 같은 방향(바깥·위)으로 더 꺾기, − 가 안쪽입니다
- **구멍 만들기**(FR-WALL-10~15): 자세 각도에 그 사람의 실제 팔다리 길이를 대입해 관절 위치를 계산하고, 아바타와 같은 굵기 규칙의 캡슐 + 여유 폭(쉬움 2.0 / 보통 1.4 / 어려움 1.0 거품) 안의 거품을 비웁니다. 그중 **정답 자세의 몸 자리(캡슐 + 거품 반 개)에는 금색 풍선**을 두고, 그 바깥 여유 폭은 빈칸으로 둡니다. 벽은 키에 비례(높이 = 키×1.2, 너비 = 키×1.25)하고 거품 수는 누구나 24×26 = 624개. 한 판에서 자세는 겹치지 않고 뒤로 갈수록 레벨이 오릅니다
- **진행**(FR-WALL-20~25): 벽 수는 7~10개 랜덤. 벽은 소실점에서 작게 나타나 원근감 있게 커지며 다가오고(첫 벽 5.5초 → 마지막 3초), **아바타 앞에 반투명하게** 그려져 구멍 사이로 내 아바타가 보입니다. 오른쪽 위에 이번 구멍 모양을 작게 미리 보여 주고, 도착 1초 전부터 3·2·1 박자음. 통과 순간 ±0.15초 안에서 점수가 가장 높은 프레임으로 판정합니다. 몸으로 채운 **금색 풍선은 반짝이며 터지고(가산)**, 몸이 닿은 **하늘색 벽 거품은 터집니다(감점)**. 그래서 웅크리면 금색을 덜 채워 점수가 낮고, 팔다리를 너무 크게 벌리면 벽이 터집니다. 금색은 몸에서 거품 1개 거리 안이면 채운 것으로, 벽 거품은 몸이 거품 안쪽으로 조금 들어가야 터진 것으로 봅니다(조금 어긋나도 봐줌). 판정 문구는 둘 다 봅니다: Perfect = 벽 0개 + 채움 75% 이상, Great = 6개 이하 + 60%, Good = 18개 이하 + 40%, 그 밖 Oops
- **점수**(SRS 4.4를 바꿈): 벽 하나 = 100/N × 채움 점수 × max(0, 1 − 터진 벽 거품/60). 채움 점수는 채운 비율 75% 이상이면 1, 20% 이하면 0, 그 사이는 비례(카메라 관절로 그린 몸은 정답보다 조금 가늘어 100%를 채우기 어려움). 총점 100점 만점. 결과 화면에 총점, 벽별 판정·채움 %·벽 거품 수·점수, Perfect 개수
- 화면 원근은 Three.js 정사영 장면에서 소실점 기준 배율로 표현했습니다(아바타와 같은 좌표계라 판정 위치가 정확히 맞음)

## 느린 노트북에서

- **자세 인식은 작업 스레드(Web Worker)에서** 돕니다. 예전에는 화면을 그리는 메인 스레드에서 인식해 인식하는 동안(노트북에서 수십 ms) 화면이 멈췄습니다. 측정해 보니 메인 스레드의 인식 부담이 1초당 360ms → 3~5ms로 줄고, 프레임 사이 최대 간격이 19~44ms → 6~7ms가 됐습니다(RTX 3050). 작업 스레드를 못 쓰는 환경(`npm run dev` 등)에서는 예전처럼 메인 스레드에서 인식합니다

- ⚙️ 설정 → **가벼운 모드**: 인식 모델 Lite + 카메라 640×480 + 화면 0.75배로 한 번에 바꿉니다(다음 실행 때도 유지)
- 화면은 창 크기 1배로만 그립니다(고해상도 노트북에서 2배로 그리지 않음). 풍선·조각은 재질을 함께 쓰고 다시 써서 가볍게 했습니다
- 인식이 18ms 넘게 걸리는 컴퓨터에서는 인식 간격을 자동으로 늘려(인식 시간의 1.8배) 화면이 먼저 부드럽게 돌게 합니다
- `--log-metrics` 로 실행하면 `infer`(인식 ms), `frame`(한 프레임 처리 ms), `render`(화면 fps), `prof[...]`(1초 동안 단계별 ms: 인식·옷 색·게임·그리기·UI, 프레임 최대 간격)가 찍혀 어디가 느린지 볼 수 있습니다

## 음원 바꾸기

지금은 효과음과 메뉴 음악을 Web Audio로 합성합니다. CC0 같은 상업 이용 가능한 무료 음원을 받으면:

1. 파일을 `public/audio/` 아래에 넣습니다(예: `public/audio/music/menu.mp3`, `public/audio/sfx/select.ogg`)
2. `public/audio/audio.json` 을 만듭니다

```json
{
  "music": { "menu": "music/menu.mp3" },
  "sfx": { "select": "sfx/select.ogg", "shutter": "sfx/shutter.ogg" },
  "credits": ["Menu music: 곡 이름 by 작가 (CC0)"]
}
```

등록한 것만 파일로 바뀌고 나머지는 합성음을 씁니다. `credits` 는 설정 화면 아래 크레딧에 나옵니다. 효과음 이름: `hover`, `select`, `back`, `beep`, `go`, `shutter`, `cheer`, `error`, `pause`, `join`, 풍선 게임 `pop`, `bomb`, `gold`, `heart`, `clock`, `star`, `bubble`, `miss`, `lifeLost`, `stageClear`, `gameOver`. 음악 이름: `menu`, `balloon`(스테이지마다 빨라짐).


거실에 어른(1.75m, 초록 옷)과 아이(1.2m, 노란 옷)가 카메라를 보고 서서 정해진 대본대로 움직이는 50초짜리 3D 영상(`test-videos/two-people.webm`)을 만듭니다. 0~6초 준비 자세 → 6~13초 아이가 손 들기 → 13~18초 어른 팔 벌려 뛰기 → 18~26초 자리 바꾸기 → 26~30초 어른 손 들기 → 30~42초 아이가 화면 밖으로 나갔다 돌아오기 → 42~50초 다시 자리 바꾸기. 1인 영상은 `npx electron scripts/make-people-video.cjs --people=1`.

실제 사람을 찍은 정면 영상(2인 포함)은 `test-videos/` 에 넣어 같은 방법으로 쓰면 됩니다(git에는 올라가지 않음).

### 아직 남은 것 / 알려진 점

- 낚시는 실제 웹캠으로 아직 해 보지 않았습니다. 정면 카메라에서는 팔을 앞으로 뻗으면 짧아 보여서, **던지기·당기기를 손 높이(어깨 기준)로** 판단합니다. 휘두르는 힘, 기다리는 시간, 게이지 빠르기는 해 보면서 `fishing` 설정으로 맞춰야 합니다

- 거울 반전은 설정 하나로 모든 게임에 적용됩니다. 끄면 벽 자세 이름의 "왼팔/오른팔"이 화면과 반대가 됩니다(판정은 화면 위치 기준이라 정상)
- 벽 게임은 실제 웹캠·아이들로 아직 해 보지 않았습니다. 다가오는 시간, 여유 폭, 자세 각도는 해 보면서 조정이 필요합니다
- 명예의 전당 사진을 눌러 그 판의 포토 스트립 다시 보기(FR-WALL-43)와 스냅샷(FR-WALL-30~32, FR-BAL-32)은 아직입니다
- "지난 보정 그대로"(FR-PLY-07)는 체형 저장까지만 했고, 고르는 화면은 아직 없습니다

- 풍선 게임 하늘 비율(`skyRatio`), 낙하 속도, 손 판정 크기는 실제로 해 보며 더 맞춰야 합니다. 콤보·황금 풍선 순간 스냅샷(FR-BAL-32)은 아직입니다

- 테스트 영상에서는 3m 떨어진 작은 아이(1.2m)를 처음 몇 초 동안 못 잡는 경우가 있습니다(MediaPipe 감지기는 얼굴이 작으면 약함). 실제 아이들 정면 영상으로 다시 확인이 필요합니다
- 두 사람이 완전히 겹치면 뒤 사람을 잠깐 놓쳐 자동 일시정지가 될 수 있습니다
